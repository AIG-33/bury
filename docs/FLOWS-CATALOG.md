# Каталог пользовательских флоу — маршруты и шаги

Полный список реализованных пользовательских сценариев с конкретными маршрутами:
и со стороны участника (игрок/гость), и со стороны создателя (организатор турнира,
владелец клуба, тренер, админ).

Смежные документы:

- [FLOWS.md](FLOWS.md) — техническая карта (Server Actions, таблицы, RLS).
- [FLOWS-USER.md](FLOWS-USER.md) — описание «что умеет приложение» простым языком.
- Раздел [«Как флоу распределены по меню»](#как-флоу-распределены-по-меню-мобильное-приложение) внизу — маппинг флоу → пункт навигации в мобильном приложении.

Обозначения маршрутов: все пути без префикса локали (`/ru`, `/en`).
`/m/*` — мобильные экраны (их видит Capacitor-приложение), рядом в скобках — веб-эквивалент.

## 1. Аккаунт: регистрация и вход

| Флоу                            | Шаги и маршруты                                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Вход (magic-link / Google)      | `/login` → e-mail (magic-link) или кнопка Google → `/api/auth/callback` → редирект по роли через `/api/auth/post-login` |
| Вход в мобильном приложении     | стартовый экран `/m` (гость) → кнопки e-mail / Google / Apple (`app/[locale]/m/start-screen.tsx`)                       |
| Восстановление пароля           | письмо-reset → `/auth/update-password`                                                                                  |
| Выход                           | «Ещё» → `Выйти` (или Настройки → Выйти) → POST `/api/auth/signout`                                                      |
| Онбординг: выбор пути           | после первого входа редирект на `/onboarding` (квиз или импорт)                                                         |
| Онбординг-квиз (стартовый Elo)  | `/onboarding/quiz` → 10 вопросов → стартовый Elo 800–2200 → редирект `/me/rating`                                       |
| Импорт рейтинга из Liga Tennisa | `/onboarding/import-lt` → поиск себя → превью → подтверждение импорта                                                   |
| Приглашение от тренера          | письмо → `/invite/[token]` → вход → привязка к тренеру → квиз                                                           |
| Удаление аккаунта               | `/account-deletion` — инструкция по удалению данных                                                                     |

## 2. Профиль игрока

**Участник (владелец профиля):**

| Флоу                           | Шаги и маршруты                                                                                                  |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Мой профиль (моб.)             | таб «Ещё» → `Мой профиль` → `/m/profile` (Elo, график, последние матчи)                                          |
| Редактирование профиля         | `/m/profile` → «Редактировать» → `/me/profile` (форма: данные, район, доступность, приватность, соцсети, аватар) |
| Привязка Telegram              | `/me/profile` → карточка «Telegram» (`telegram-link-card.tsx`)                                                   |
| Внешний рейтинг (Liga Tennisa) | `/me/profile` → карточка «Внешний рейтинг»: обновить / отвязать / привязать (→ `/onboarding/import-lt`)          |
| Мой рейтинг и история Elo      | `/me/rating` (график, история); в моб. — график на `/m/profile`                                                  |
| Стать тренером                 | «Ещё» → `Стать тренером` → `/me/become-coach` (форма + документы) → модерация админом (§10)                      |

**Другая сторона (зрители):** публичная карточка игрока `/players/[id]`; каталог игроков `/players`.

**Организатор (любой зарегистрированный пользователь):**

| -------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Создать турнир       | «Ещё» → `Организация турниров` → `/me/tournaments/organized` → «Создать турнир» (диалог: формат, правила, дата, площадка) |

| Статус и приватность | там же: статус (черновик → регистрация → идёт → завершён), публичный/приватный, ссылка для регистрации                    |

| Турниры клуба        | панель владельца клуба `/me/clubs/owned/[id]` → секция «Турниры клуба»                                                    |

## 4. Матчи, счёт и поиск игры

**Участник:**

| Флоу                          | Шаги и маршруты                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| История матчей и статистика   | таб «Матчи» → `/m/matches` (веб: `/me/matches`) — фильтры, W/L, форма                        |
| Записать счёт                 | FAB «Играть» → `записать счёт` → `/m/record` (соперник, формат, сеты, прогноз ±Elo)          |
| Подтвердить / оспорить счёт   | `/me/matches` → карточка матча → «Подтвердить» (пересчёт Elo) или «Оспорить»                 |
| Быстрая регистрация матча     | `/me/matches` → «Быстрая регистрация» (диалог)                                               |
| Отмена запланированного матча | `/me/matches` → карточка → «Отменить»                                                        |
| Спарринги (открытые матчи)    | FAB «Играть» → `Матч` → `/m/game` (веб: `/open-matches`); сегменты Найти / Мои заявки        |
| Откликнуться на спарринг      | `/m/game` → «Играть» у карточки (веб: `/open-matches/[id]` → отклик)                         |
| Создать открытый матч         | `/m/game` → карточка «Ищешь соперника?» (веб: `/open-matches/new`)                           |
| Найти соперника (подбор)      | «Ещё» → `Подбор соперника` → `/me/find` (район, Elo±, время, LT-фильтры) → «Предложить матч» |
| Предложения матчей            | «Ещё» → `Предложения матчей` → `/me/find/proposals` — принять / отклонить                    |
| Публичная лента матчей        | `/matches` — последние подтверждённые матчи (гостям тоже)                                    |

**Другая сторона:** соперник получает e-mail о предложении/счёте и подтверждает у себя в `/me/matches`; организатор спарринга управляет заявками в `/m/game?tab=mine` (веб: `/open-matches/[id]`).

## Как флоу распределены по меню (мобильное приложение)

Нижний таб-бар (5 слотов) показывается на всех экранах приложения: на `/m/*` его
рендерят сами экраны (на детальных экранах CTA-бар ставится над таб-баром через
`MCtaBar aboveTabBar`), на обычных веб-страницах внутри нативной оболочки его
инжектит `NativeTabBar` (`app/[locale]/layout.tsx` →
`components/mobile/native-tab-bar.tsx`), включая страницы редактирования
профиля, управления турнирами и клубами, разделы `/coach/*` и `/admin/*`.

### Таб-бар

| Таб          | Экран            | Покрывает флоу                                                                                             |
| ------------ | ---------------- | ---------------------------------------------------------------------------------------------------------- |
| Главная      | `/m`             | дашборд, ближайшие события, быстрые действия, лента                                                        |
| Турниры      | `/m/tournaments` | каталог, карточка, заявка, мои турниры (§3, участник)                                                      |
| Играть (FAB) | action-sheet     | Матч → `/m/game` (спарринги); Занятие → `/m/coaches`; записать счёт → `/m/record`; бронь корта → `/venues` |
| Матчи        | `/m/matches`     | история, статистика, подтверждение счёта (§4)                                                              |
| Ещё          | `/m/more`        | всё остальное — группы ниже                                                                                |

### Экран «Ещё» (`/m/more`)

| Группа       | Пункт → маршрут                                                                                                                  | Кому виден                |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| Профиль      | Мой профиль → `/m/profile`; Моя статистика → `/m/matches`; Динамика рейтинга → `/me/rating`                                      | вошедшим                  |
| Игра         | Подбор соперника → `/me/find`; Предложения матчей → `/me/find/proposals`                                                         | вошедшим                  |
| Игра         | Спарринги · открытые матчи → `/m/game`                                                                                           | всем                      |
| Соревнования | Рейтинг · лидерборд → `/m/rating`                                                                                                | всем                      |
| Соревнования | Мои турниры → `/m/tournaments?tab=mine`; Организация турниров → `/me/tournaments/organized`; Мои записи и брони → `/me/bookings` | вошедшим                  |
| Сообщество   | Клубы → `/m/clubs`; Тренеры → `/m/coaches`; Игроки → `/players`; Площадки и корты → `/venues`                                    | всем                      |
| Сообщество   | Мои клубы → `/me/clubs`; Управление клубами → `/me/clubs/owned`; Мои тренеры → `/me/coaches`                                     | вошедшим                  |
| Управление   | Панель тренера → `/coach/dashboard` (внутри — SectionNav: игроки, слоты, профиль тренера)                                        | `is_coach` или `is_admin` |
| Управление   | Панель администратора → `/admin` (внутри — SectionNav: площадки, заявки тренеров, БД, квиз, рейтинг, отзывы)                     | `is_admin`                |
| Аккаунт      | Уведомления → `/m/notifications` (бейдж)                                                                                         | вошедшим                  |
| Аккаунт      | Настройки → `/m/settings`; Помощь → `/help`; Поддержка → `/support`                                                              | всем                      |
| Аккаунт      | Стать тренером → `/me/become-coach`                                                                                              | вошедшим без роли coach   |
| —            | Выйти (POST `/api/auth/signout`)                                                                                                 | вошедшим                  |

### Флоу, достижимые не из меню (по построению)

- Онбординг (`/onboarding`, `/onboarding/quiz`, `/onboarding/import-lt`) — редирект после первого входа; импорт LT также из карточки «Внешний рейтинг» в `/me/profile`.
- Приглашения (`/invite/[token]`, `/clubs/join/[token]`) — по ссылке из письма/мессенджера.
- Приватность (`/privacy`) — из Настроек; удаление аккаунта (`/account-deletion`) — из `/privacy` и сторов.
- Привязка Telegram — карточка в `/me/profile`; канал Telegram — тумблер в `/m/settings`.
- Отзыв на тренера — форма на странице тренера `/coaches/[id]`.
- Смена пароля (`/auth/update-password`) — по ссылке из письма-reset.
